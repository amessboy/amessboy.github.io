外贸发展如火如荼，作为零经验小白，看完下面这篇文章，你就能从 0 到 1 开出一个能稳定出单的店铺。
# 1、锁定站点与模式
### 站点
美国站流量最大、规则最透明，新手先啃下来；欧洲 VAT 复杂，可放在第二梯队。  
### 模式
FBA（Fulfillment by Amazon）为主，FBM（自发货）为辅——FBA 帮你贴 Prime 标签，转化率能高 20% 以上。
### 决策工具
Helium 10/Xray 插件看市场容量、Jungle Scout 评估竞品利润。

# 2、注册前准备——资料“三件套”

 **企业资质**：营业执照（个体工商户即可）、法人身份证正反面高清扫描件。

**财务工具**：  双币信用卡（Visa/MasterCard，扣月租 39.99 USD/月）。
海外收款账号（万里汇 WorldFirst、PingPong、连连都可，结汇费率 0.3–1%）。

**网络环境**：如果你因网络无法登录，那么使用文章末尾的魔法工具可解决这一问题。
# 3、正式注册账号（以美国站为例）

打开 [https://sellercentral.amazon.com](https://sellercentral.amazon.com/) → Sign up → 选 Professional 计划。

填公司英文名称（与执照拼音一致）、地址、电话、邮箱。
 
上传执照+身份证→ 触发视频验证（2024 年后 90% 都会触发）。预约中文客服，法人手持身份证 10 分钟搞定。

税务问卷：选 W-8BEN（非美国人免税），填完立刻生效。

审核 1–3 天，收到 “Your Amazon seller account has been activated” 即成功 。

# 4、后台基础设置

**登录**：每次先开 VPN → 输入二次验证码（Google Authenticator）。  

**配送模板**：Settings → Shipping Settings → 新建模板：Standard(7–10 天)/Expedited(3–5 天)。  

**收款**：绑定万里汇提供的美国银行账号（ABA+Account Number）。 

**品牌备案（可选）**：R 标回执即可申请 Brand Registry，立刻解锁 A+ 页面、Vine 评论、防跟卖。

# 5、选品与供应链

**选品公式**：轻小件 + 非季节 + 15–40 USD 客单价 + 毛利≥30%。  

**找工厂**：1688 深度验厂 + 阿里巴巴跨境金牌供应商，签“贴牌/可中性包装”协议。  

**质检**：第三方验货（SGS/BV），低于 500 件抽检 50 件。  

**物流**：美森快船 12 天入仓，空派快线 7 天补货。

# 6、Listing上架——把“人找货”变成“货找人”

**创建商品**：Inventory → Add a Product → 填 UPC/EAN（GS1 官网买正规码）。

**标题**：200 字符以内，核心关键词往前放，如“Dog Nail Clippers – Professional Pet Grooming Tool with LED Light”。

**图片**：7 张主图+3 张 A+图，主图 2000×2000 px，白底，角度 15°。

**Bullet Points**：5 行埋词+场景化；Description 用 HTML 简单排版。

**价格**：首批 30–50 个 FBA，定价 = 竞品 90% 先抢购物车，后期再提价。

# 7、流量启动——新品黄金 90 天打法

 **第 1–7 天**：自动广告（$30/天）跑词，搜词报告导出高转化词。  
 
 **第 8–30 天**：手动精准+词组广告，预算逐步放大，ACOS 控制 ≤30%。  

**促销**：Coupon 10%，限时秒杀（7 DD）冲排名。  

**Review**：早期评论员计划（已停）→ Vine 30 个免费测评，留评率 80% 以上 。  

**站外**：FB Deal 群+红人 20 美金开箱视频，带来首日 50 单“动销”。

# 8、库存与账号风控

**补货公式**：日均销量 × 采购周期 × 1.2 安全库存，用 SoStocked 自动提醒。  

**绩效监控**：每天后台首页关注 ODR、迟发率、Policy Violations。  

**防跟卖**：Brand Registry + Transparency 条码 + 自有包装差异化。

# 9、复制与扩张

**多站点**：美国站跑通后，一键同步到加拿大、墨西哥（NARF 计划），仓租 0 增加。  
**多平台**：同套 Listing 复制到 eBay/Walmart，库存共享。

**团队**：3 人小组——选品/运营/客服，用 Asana 管理 SOP，月销 10 万美金可复制。

**时间线参考**:
0–1 个月：注册+发首批 FBA  。

2–3 个月：日出 10–30 单，稳定盈利  。

4–6 个月：第二、第三条产品线，月销 5–10 万美金 。

7–12 个月：品牌旗舰店+站外独立站，估值×3 倍。

**一句话总结**：把亚马逊当作“外贸放大器”，先跑通最小闭环（注册→FBA→广告→回款），再用数据驱动扩品、扩站、扩渠道。祝你也能把“Made in China”卖成“Brand on Amazon”。
