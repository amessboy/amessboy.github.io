# 1、常见问题

**Q**1：v2plus 安全吗？
**A**：安全，不会泄露个人隐私。
**Q2**：v2plus 免费吗？
**A**：每个用户都有免费两星服务。
# 2、节点相关

**Q**1：v2plus 支持哪些协议？
**A**：支持VMess(V2Ray)、VLESS(Xray)、Trojan、Socks、Shadowsocks(SS)等代理协议。

# 3、**更多 v2plus 常见问题**

**Q1**：打不开网页？
**A**：- 检查是否启用“系统代理”（“清除系统代理” 是否切换为 “自动配置系统代理”）。或尝试更换其他节点线路（ctrl A+R：测试延迟，ctrl A+T 测速）。

**Q2**：系统杀毒报错？
**A**：纯属误报，可添加信任目录。

**Q3**：如何开机自启？
**A**：设置 → 常规设置 → 勾选“开机启动”。
