# 2、**更多 v2plus 常见问题**

**Q1**：打不开网页？
**A**：- 检查是否启用“系统代理”（“清除系统代理” 是否切换为 “自动配置系统代理”）。或尝试更换其他节点线路（ctrl A+R：测试延迟，ctrl A+T 测速）。

**Q2**：系统杀毒报错？
**A**：纯属误报，可添加信任目录。

**Q3**：如何开机自启？
**A**：设置 → 常规设置 → 勾选“开机启动”。

## 3、 无法连接或代理无法正常工作？

请确保你的网络连接正常。检查配置是否正确，特别是代理设置和端口是否与你的需求匹配。

## 4、软件无法启动或崩溃？

尝试重新启动软件。如果问题持续，可以尝试重新安装软件或者查看错误日志以了解具体原因。

## 5、无法打开特定网站/APP？

检查代理设置或尝试更改路由规则。某些网站可能会被限制，需要调整代理规则以访问。还可以开启全局代理模式，如果是某些特定的软件无法使用，请尝试开启Tun模式。
