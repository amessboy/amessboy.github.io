# 魔法科学 V2Plus 诞生记-为高效易用而生

![](asserts/0619.png)

身为外贸人， 不可避免的需要翻墙出去一下。花钱不少，但效果不佳。

## 一、目前市场上翻墙软件普遍存在以下问题

（1）需要动手找订阅更新订阅买订阅等，挺费时费事的。

（2）需要动手测试节点， 节点通常不稳定，测试节点删除不可用的节点,挺费时的。

（3）遇到 提示“运行 Core 失败，请看日志”, 然后就没有然后了， 这真让人受不了。

  于是想能不能全自动化？基本逻辑如下：软件自动定时的测试节点，保留可用的代理节点；然后再通过代理又去自动的更新订阅节点；再然后又是定时的测试节点...如此实现“内燃机”式的循环往复。于是春节期间抽时间动手在 V2rayN 的基础上进行增强改进，最终形成了 V2Plus。正如其名， V2Plus 是 v2rayN 的增强改进版， 与 v2rayN 保持兼容。

## **二、V2Plus 目前实现了以下功能**

（1）自动去重，自动删除不可用的节点。

（2）设定定时全自动的测试节点，并自动的更新订阅节点、自动排序并选择最快的节点。这个功能用着应该挺舒服的了。

（3）如果无节点可用时，自动发邮件通知；当然你需要在设置中打开开关。

（4）自动更新订阅列表，按不同会员等级，所能获得的订阅列表个数，最大节点数量有所不同。对于大多数用户日常上网，使用注册免费 2 星级就够了。

（5）注册防失联机制。目前任何上网工具都会表示得不稳定， 这既有防火墙的原因， 也有线路的原因。 当完全无节点可用时，进行失联援助是可靠的方式。

（6）增加有效节点的真实国家显示。由于使用 web API 查询， 目前效率不高， 仅针对测速通过的节点进行测试。这对于国外网站的区域限制是非常有效的。

（7）集成 Proxifier, 用户可以按进程、按访问目标进行流量劫持， 实现更加精准的上网需求。

## **三、V2Plus 怎么使用**

（1）本着绿色环保理念，下载操作系统对应的版本软件，解压可以运行， 绿色无需安装。目前仅 windows x64 是可供下载的， 其他平台正在适配中，请注意网站更新消息。

(2)设置通知邮件相关信息，目的时当无节点可用时，自动给您发邮件， 不过非专业人员设置这些信息有点困难。

（3）此外推荐您设置开机自动启动、开机时最小化、显示下载速度等。 您也可以自行设置测试的时间间隔、自动发邮件、无节点可用时自动启动测试等。

## **四、谈谈我的使用感受**

（1）对于新手， 打开 V2Plus"自动配置系统代理"的全局模式，就可以上网了。 缺点是节点不可用时会阻碍正常上网。

（2）推荐大多数人："Edge/Chrome + SwitchyOmega 扩展插件+V2Plus 清除系统代理" 三者组合上网方案。 当要上外网时，就切换 SwitchyOmega 代理模式， 否则就不用了。 因为使用代理访问国内的网站有时是会卡的。平时就是开机启动， 清除系统代理 模式， 不会干扰到我们其他的工作。

（3）特殊场景： V2Plus+Proxifier 设定好要上网的程序，设定上网的规则即可直接冲浪。例如：对于 Photoshop.exe 程序可以用这种方法使用 AI 生成式的功能。

## **五、问题解决**

（1）节点存在但上不了外网。先请访问测试 google.com,如果工作正常，则问题出在其他方面而不是代理节点的问题；再切换一下节点试试， 如能正常访问 google，则说明前一个节点可能已经死了；也可以检查一下浏览器插件（如果有）模式是否正确；

（2）排除无效节点和测试 IP 地理位置，目前还是效率还不算高， 所以在设置总的测试时间间隔时， 推荐为 30 分钟， 避免电脑不停的在测试。我们将进一步优化自动判断不可用节点的逻辑.

   （3）已经没有可用节点了，系统却不自动发起测试。 默认情况下是 30 分钟测试一次。 你可以手动 Ctrl+E 触发测试， 也可以打开设置项“无节点可用时自动测试”， 在设置/参数设置/V2Plus 设置/中。
